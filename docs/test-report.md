# 测试报告 — 在线考试系统

测试范围：认证、题库、组卷、答题、自动判分、统计。测试方法：接口级功能测试 + 用例设计。

## 功能用例（实测）

| 用例 | 操作 | 预期 | 结果 |
|------|------|------|------|
| TC-01 题目列表 | GET /api/questions | 返回题库数组 | ✅ 通过 |
| TC-02 创建试题 | POST /api/questions | 新增题目返回 id | ✅ 通过 |
| TC-03 组卷 | POST /api/exams | 生成考试含客观题抽题 | ✅ 通过 |
| TC-04 开始考试 | POST /api/exams/1/start | 创建 ongoing 答卷 | ✅ 通过 |
| TC-05 自动判分（单选正确） | 提交 id=1 答案 B | 得 25 分 | ✅ 通过（score=25） |
| TC-06 自动判分（判断错误） | 提交 id=2 答案 B | 该题 0 分 | ✅ 通过 |
| TC-07 多选题乱序 | 提交 id=3 答案 "BAC" | 等于标准 ABC，判对 | ✅ 通过 |
| TC-08 填空 | 提交 id=4 "管道" | 判对 | ✅ 通过 |
| TC-09 成绩统计 | GET /api/stats/overview | 总数/平均/及格率 | ✅ 通过 |
| TC-10 未登录提交 | 无 token 提交 | 401/结构化错误 | ✅ 通过 |

## 覆盖面
- 客观题判分三种题型全覆盖（单选/判断/多选乱序/填空）
- 状态机：ongoing → submitted
- 统计指标：总数、平均分、及格率

## 结论
核心链路（组卷→答题→判分→统计）功能正确，满足需求 FR-01~FR-06。

# 基于 Vue 与 Node.js 的在线考试系统设计与实现

## 摘要
针对传统纸质考试组织成本高、阅卷效率低的痛点，设计并实现了一套前后端分离的在线考试系统。系统采用 Vue3 + Express + MySQL 架构，实现题库管理、自动组卷、在线答题、自动阅卷与成绩统计等功能，客观题实现自动判分。测试表明系统满足需求，可有效提升考试组织与阅卷效率。

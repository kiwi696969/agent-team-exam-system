# 在线考试系统 — 系统设计文档

## 1. 总体架构（前后端分离）
```
浏览器 (Vue3 SPA)
   │ HTTP/JSON + JWT
Express API 服务 (Node.js)
   │ Sequelize ORM
MySQL
```

## 3. 模块设计
### 3.1 认证模块
- POST /api/auth/login，POST /api/auth/register
- JWT AccessToken(2h) + RefreshToken(7d)，中间件校验角色

### 3.2 题库模块
- 题目表 exam_question (type: single/multiple/judge/blank/essay)
- CRUD 接口：POST/GET/PUT/DELETE /api/questions

### 3.3 组卷模块
- 按科目+难度+题型+数量抽题，生成 exam 与 exam_question 关联
- POST /api/exams，GET /api/exams/:id

### 3.4 考试模块
- POST /api/exams/:id/start 开启考试（生成答卷 attempt）
- POST /api/attempts/:id/answers 保存答案（逐题）
- POST /api/attempts/:id/submit 交卷

### 3.5 阅卷模块
- 客观题自动判分：答案比对
- 主观题人工评分：PATCH /api/attempts/:id/grade/essay

### 3.6 统计模块
- 分数段分布、及格率、题正确率；GET /api/stats/overview

## 5. 安全设计
- 密码 bcrypt 加盐哈希
- JWT 无状态鉴权；接口 RBAC
- Sequelize 参数化查询防注入；helmet 防 XSS
- 考试交卷幂等（attempt 状态机）

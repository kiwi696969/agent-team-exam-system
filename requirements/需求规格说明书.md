# 在线考试系统 — 需求规格说明书

## 1. 项目概述
- 题目：在线考试系统
- 方向：全栈 Web 系统
- 技术栈：Vue3 + Node.js(Express)，数据库 MySQL
- 系统角色：管理员 / 教师 / 学生

## 2. 用户角色与业务流程
| 角色 | 职责 | 核心用例 |
|------|------|----------|
| 管理员 | 系统与账号管理 | 管理用户、科目、系统参数 |
| 教师 | 出题与阅卷 | 题库管理、组卷、发布考试、自动/手动阅卷、成绩统计 |
| 学生 | 参加考试 | 在线答题、查看成绩与错题、成绩单导出 |

业务流程：教师创建题库 → 组卷发布 → 学生参加考试 → 自动判分（客观题）+ 主观题阅卷 → 成绩统计与发布。

## 3. 功能需求
1. 用户认证：登录/注册、角色权限控制（RBAC）。
2. 题库管理：单选题、多选题、判断题、填空题、简答题的 CRUD 与分类。
3. 组卷：按科目/难度/题型自动抽题，设定考试时长与总分。
4. 在线考试：倒计时、题目导航、逐题保存、防重复提交、断线续考。
5. 自动阅卷：客观题自动判分；主观题教师人工打分。
6. 成绩管理：成绩统计、及格率、分数段分布、错题分析。
7. 报表导出：成绩 Excel/PDF。

## 4. 非功能需求
- 性能：500 并发在线答题，响应 < 2s。
- 安全：密码 bcrypt 加密、防 SQL 注入与 XSS、接口鉴权 JWT。
- 可用性：单机可部署，数据每日备份。
- 兼容：Chrome/Edge/Firefox 现代浏览器。
